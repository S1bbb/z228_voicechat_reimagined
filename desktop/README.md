# ZALUPA228 Desktop (Windows)

Оболочка на [Tauri v2](https://tauri.app) вокруг сайта z228: окно показывает сайт **с вашего сервера**, а Rust
добавляет то, чего не умеет браузер:

- **глобальные клавиши поверх игр** — рация (удержание), мьют, оглушение; клавиши, сочетания с Ctrl/Shift/Alt,
  боковые кнопки мыши (Mouse4/Mouse5). Нажатие не перехватывается — клавиша доходит и до игры;
- **звук рации** — тихий щелчок на нажатие и отпускание;
- **трей** — крестик сворачивает окно в трей, голос продолжает работать; иконка показывает состояние
  (серая — не в голосе, обычная — в голосе, зелёная точка — говорю, красная — мьют/оглушение);
- **вход одной строкой** с проверкой сертификата сервера (пин SPKI SHA-256);
- **ярлык на рабочем столе** — предлагается при первом входе, его можно создать и потом:
  «Настройки → Приложение → Ярлык»;
- **автообновление** через GitHub Releases.

## Установка

Скачайте `ZALUPA228_…_x64-setup.exe` из [релизов](https://github.com/S1bbb/z228_voicechat_reimagined/releases)
и запустите. Права администратора не нужны: приложение ставится только для текущего пользователя.

Установщик не подписан сертификатом кода, поэтому при первом запуске Windows покажет
**«Windows защитила ваш компьютер»** → нажмите **«Подробнее» → «Выполнить в любом случае»**.

### Первый запуск

Приложение попросит **строку-приглашение**. Её делает админ сервера: «Настройки → Администрирование →
Ссылка для десктопа» — выбрать ключ и нажать «Копировать». Строка выглядит так:

```
z228://203.0.113.10:3443/?fp=<отпечаток сертификата>&k=<ключ доступа>&n=<название>
```

`fp` — отпечаток ключа сертификата сервера: по нему приложение узнаёт «свой» сервер с самоподписанным
сертификатом и не откроет подменённый. Если сервер перевыпустит ключ, приложение покажет ошибку и попросит
новую строку. Вместо строки можно вставить обычную ссылку `https://…/#k=…` и отдельно отпечаток
(для сервера с сертификатом Let's Encrypt отпечаток не нужен).

### Если клавиши не работают в игре

Игра, запущенная **от администратора**, не пускает к себе клавиши из обычных программ — запустите
ZALUPA228 тоже от администратора. Приложение само предупредит, если заметит такое окно.
Клавиши ловятся низкоуровневыми хуками Windows, как в Discord; некоторые античиты такое не любят.

## Разработка

Нужны Rust (stable, MSVC), Node.js 20+ и WebView2 Runtime (в Windows 10/11 уже есть).

```bash
cd desktop
npm install
npx tauri dev        # отладочный запуск
npx tauri build      # установщик в src-tauri/target/release/bundle/nsis/
cd src-tauri && cargo test
```

Сервер для проверки: `go run ./cmd/server -web-dir web/static` (из корня репозитория) — строку-приглашение
возьмите в админке по адресу `https://127.0.0.1:3443`.

Настройки приложения: `%APPDATA%\ZALUPA228\config.json` (сервер, отпечаток, клавиши). Данные сайта
(ник, ключ, настройки звука) — в папке WebView2 `%LOCALAPPDATA%\ru.zalupa228.desktop`.

В отладочной сборке переменная `Z228_DEVTOOLS_PORT=9333` включает удалённую отладку WebView2
(Chrome DevTools Protocol) — так окна можно проверять скриптом.

### Устройство

| Файл | Что делает |
|---|---|
| `src/bridge.rs` | окна, трей, команды `desktop_*` и события для страницы, запуск приложения |
| `src/hooks.rs` | `WH_KEYBOARD_LL` + `WH_MOUSE_LL` в своём потоке, запись клавиш, задержка отпускания рации, сторож хуков |
| `src/webview2.rs` | пин сертификата (`ServerCertificateErrorDetected`), разрешения микрофона/камеры |
| `src/pin.rs` | TLS-проверка сервера (rustls) и SPKI SHA-256 |
| `src/invite.rs` | разбор строки-приглашения |
| `src/tray.rs` | иконки состояний, меню трея |
| `src/update.rs` | проверка и установка обновлений |
| `ui/connect.html` | экран первого входа |
| `../web/static/js/desktop.js` | мост на стороне сайта |

Странице сервера доступны только команды `desktop_*` — права выдаются во время работы для адреса из
настроек. Окну входа — только `connect_*` (`capabilities/default.json`).

## Релиз

1. Один раз: добавить в секреты репозитория (Settings → Secrets → Actions)
   `TAURI_SIGNING_PRIVATE_KEY` (содержимое приватного ключа подписи обновлений) и
   `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Публичный ключ уже в `src-tauri/tauri.conf.json`.
   **Приватный ключ в репозиторий не коммитить**: потеряете его — уже установленные приложения
   перестанут принимать обновления.
2. `git tag desktop-v0.1.1 && git push fork desktop-v0.1.1` — workflow `.github/workflows/desktop.yml`
   соберёт установщик, подпишет обновление и опубликует релиз с `latest.json`.

Приложение проверяет обновления при запуске и раз в 6 часов по адресу
`https://github.com/S1bbb/z228_voicechat_reimagined/releases/latest/download/latest.json` и ставит их только
после нажатия «Обновить и перезапустить». Для этого **репозиторий должен быть публичным** — иначе GitHub
не отдаст `latest.json` без токена.
