# Заметки для агентов

- **Деплой на VPS** — только по [docs/deploy-vps.md](docs/deploy-vps.md) (скрипт `scripts/deploy-vps.sh`).
  Трогать только сервис `z228`, остальное на сервере не наше. Адреса, пароли и ключи в репозиторий не писать.
- Сайт (`web/static`) вшит в серверный бинарь: правка фронтенда = пересборка и деплой.
- В `main` пушат и другие агенты: перед работой и деплоем `git fetch` + `merge --ff-only`, пушить только fast-forward.
- Проверка перед коммитом: `go vet ./... && go test ./...`, `node --check web/static/js/*.js`.
- Новые записи «Что нового» — в начало `NEWS` в `web/static/js/whatsnew.js` (id растёт).
- Новые столбцы/таблицы БД — через `migrate` в `internal/store/extra.go` (только добавлять, ничего не удалять).
- Внешний вид проверять во всех дизайнах (классический, «Графит 2.0», «Острова») и в светлой теме.
